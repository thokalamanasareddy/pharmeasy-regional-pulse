# PharmEasy Regional Pulse

A local, reproducible regional performance intelligence pipeline built with Python, pandas, SQLite, Streamlit, and Plotly. No API keys or paid services are required.

## Run the full pipeline

From the repository root, create and activate a virtual environment once, then run these **three project commands**:

```bash
pip install -r requirements.txt
python3 run_pipeline.py
streamlit run app.py
```

On Windows, activate the virtual environment with `.venv\\Scripts\\Activate.ps1`; on macOS/Linux use `source .venv/bin/activate`. The pipeline generates the deterministic dataset, cleans and validates it, builds SQLite tables, prints SQL checks, calculates month-on-month changes and state persistence, drafts the CII narrative, and tests the approve/edit/reject review gate. The dashboard runs locally and requires no API key.

## Repository artifacts

- `run_pipeline.py` — runs the end-to-end pipeline stages in order.\n- `generate_dataset.py` — deterministic source data generator.
- `clean_data.py` — cleaning, imputation, schema validation, and quality report.
- `data_quality_report.md` — data-quality dimensions and fixes.
- `build_db.py` and `queries.py` — SQLite tables, join checks, null-count pitfall, and region/month metrics.
- `metrics_engine.py` — MoM changes, operational threshold flags, and JSON state persistence.
- `draft_report.py` — Context–Insight–Implication narrative generation.
- `memo.md` — one-page recommendation memo with risk tags.
- `review_gate.py` and `audit_log.jsonl` — human review gate and audit trail.
- `reliability_checklist.md` — safety, validation, critique/refine, and sign-off checks.
- `app.py` — local interactive Streamlit dashboard.
- `presentation_storyline.md` — executive and regional-manager framings plus pushback Q&A.

## Evaluation cover note — consume in this order

1. **Headline finding:** The provided brief identifies Guntur's April-to-May 2026 sales movement as +122.19%; verify the April and May totals against the generated SQL metrics before final sign-off.
2. **Streamlit dashboard:** `app.py` — live exploration of KPIs, monthly trends, regional comparisons, category share, and order detail.
3. **CII narrative:** generated by `draft_report.py` and embedded in the dashboard through its executive summary — the data meaning and review prompts.
4. **One-page memo:** `memo.md` — recommendation and explicit verification-risk tags.
5. **Presentation storyline:** `presentation_storyline.md` — how to explain and defend the finding for executive and regional-manager audiences.
6. **Reviewer order:** open the dashboard first, read the CII narrative, review `memo.md`, then use `presentation_storyline.md` for the live discussion.
7. **Unverified assumption:** The cleaned export represents comparable and complete regional order activity in both months; the dataset alone cannot prove that source capture and business conditions were unchanged.

## Important interpretation note

The 8% threshold is a fixed operational alert rule, not a statistical significance test. Flags indicate that a human should inspect the data; they do not prove cause. Profit values that were missing in the source are imputed, so profit totals should be interpreted accordingly.
